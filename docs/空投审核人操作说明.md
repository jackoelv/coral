# CKEY 空投审核人操作说明

适用对象：负责核对名单并决定是否发放的审核人。  
操作页面：https://www.freedao.life/admin/airdrop  
登录要求：必须使用管理员发给你的审核人钱包登录。别的钱包打得开网站，也进不了这个页面。

审核人看不到上传按钮，也不能上传 CSV。你看到的是编辑人已经上传的批次。标成「线下社区空投」的批次会显示每个地址、算出的 CKEY，以及上传时从 IDO 合约读到的链上入金。只有编辑人已经「提交上链」、状态为「待审核」的批次，才能通过或驳回。

通过并发放会在链上记下每个地址可以领取的数量。币仍留在空投合约里，用户之后自己领取。驳回不转出任何 CKEY。

## 1. 进入页面

1. 用审核人钱包登录 https://www.freedao.life 。
2. 打开 https://www.freedao.life/admin/airdrop 。
3. 确认页面标题是「空投发放」。页面说明是：通过时提交完整名单，必须和编辑人提交上链的名单完全一致。
4. 看「还可以发放」。这是合约里目前还能拿来发放的 CKEY。读不到这个数字时，通过按钮保持关闭，不要想办法绕过。
5. 看「单个地址单次不超过」。这是每一个地址在这一次发放里允许的最大数量，默认 500 CKEY，管理员可以改。以页面上的数字为准。

浏览器里钱包当前选中的账户，必须就是登录网站的这个地址。选错账户时，签名会失败。每次签名还需要钱包里有少量 BNB 支付手续费。

你不能审核自己提交的批次。页面如果写着「不能审核自己提交的批次」，把该批次留给另一位审核人。

## 2. 审核前核对什么

对待审核批次，逐行核对，不要只看合计：

- 地址是不是完整的 `0x` 地址，有没有明显抄错、测试地址或交易所充值地址。
- 金额是不是 CKEY 的枚数。页面上的 `100 CKEY` 就是 100 枚，不是 100 个最小单位。
- 每一个地址有没有超过页面上的单次上限。
- 理由是否说得通，是否和这次活动一致。
- 这一批的合计有没有超过「还可以发放」。
- 提交人是不是这次负责发名单的编辑人。

编辑人提交上链时，钱包里只有名单哈希、条数和合计。你点通过时，钱包里才会出现完整的地址和金额。签名前，钱包里的名单必须和页面上这一批一致。不一致就取消签名，不要继续。

## 3. 通过并发放

下面几个条件同时满足，「通过并发放」才可以点：

- 状态是「待审核」。
- 这一批不是你自己提交的。
- 每个地址都不超过单次上限。
- 合计不超过「还可以发放」，并且余额能读到。
- 合约没有暂停。

操作：

1. 再次看完表格。
2. 点「通过并发放」。
3. 在钱包里核对完整地址和金额。一致才签名。

签名成功并被合约接受后，状态变为「已发放」。页面提示「已在链上发放」。

这一步的后果：

- 名单上的每个地址获得相应的可领取额度。多批额度会累加。
- CKEY 还没有转到用户钱包。用户要用名单上的那个钱包登录个人中心，点「立即领取」，才会转出。
- 这一批不能在审核页面修改、删除或自行撤回。
- 如果签完才发现地址或金额错误，立刻联系管理员，说明批次和错误内容。不要再对同一批点通过。收回未领取额度只能由管理员处理。

余额不够、超过单次上限、或暂时读不到余额时，通过按钮保持关闭，钱包不会打开。把页面上的原文告诉编辑人或管理员，不要重复点击。

## 4. 驳回

名单有错误、理由不对、或编辑人要求撤回尚未发放的批次时，点「驳回」。

驳回前可以在「备注（可选）」里写原因，最多 200 字。备注会留在这批记录上。

只有已经提交上链、状态为「待审核」的批次才能驳回。还是草稿的名单，由编辑人自己删除，审核人驳回不会成功。

驳回需要审核人钱包签名。成功后状态变为「已驳回」，不转出 CKEY，已有的可领取额度也不会被这次驳回清掉。编辑人需要另传一份新的 CSV，形成新的一批。

合约暂停时，不能再通过发放，但错误的待审核名单仍然可以驳回。

## 5. 签名之后页面没有更新

不要再点一次「通过并发放」或「驳回」，以免重复签名。

点「重新核对链上结果」。这个按钮只查询链上并补登记，不会发起新的转账。

- 链上已经成功：页面变成「已发放」或「已驳回」。
- 链上还查不到：等几分钟再核对。
- 交易已回滚：页面会解除等待。看清原因后，再决定要不要重新签名。

## 6. 各操作的后果

| 操作 | 是否要钱包签名 | 是否转出 CKEY | 结果 |
| --- | --- | --- | --- |
| 打开页面查看 | 否 | 否 | 只读名单、余额和上限。 |
| 通过并发放成功 | 是 | 先记入用户可领取额度。用户自己领取时才转到用户钱包。 | 批次变为「已发放」，不能在本页撤回。 |
| 驳回成功 | 是 | 否 | 批次变为「已驳回」。编辑人必须另传新文件。 |
| 余额不足或超过单次上限时点通过 | 否，按钮关闭 | 否 | 没有签名。 |
| 重新核对链上结果 | 否 | 否 | 只补登记已有交易，不产生新发放。 |
| 删除草稿 | 审核人没有这个按钮 | 否 | 草稿由提交它的编辑人删除。 |

## 7. 注意事项

私钥和助记词只放在你自己的钱包里。网站不会向你要私钥或助记词。任何让你导出私钥、朗读助记词、或把助记词输入网页的要求，都不要照做。

如果审核人钱包的私钥或助记词已经泄露，或者你怀疑已经泄露：

1. 立刻停止用这个钱包签名。不要再点通过或驳回。
2. 马上告诉管理员：哪一个地址可能不安全、大约什么时间发生。不要把私钥或助记词发给管理员，也不要发到群里。
3. 等管理员关掉旧地址并启用新钱包。在管理员确认旧地址已经失效之前，不要用它做任何签名。泄露的审核人钥匙有可能被别人拿去通过一份名单，所以这一步要快。
4. 使用管理员给你的新审核人钱包重新登录后，再继续未完成的审核。

其他事项：

- 一个地址不能同时当编辑人和审核人。页面提示无法进入时，把完整地址发给管理员核对。
- 通过之前，钱包弹窗是最后一次核对。弹窗里的地址或金额和页面不同，取消签名，并联系管理员。不要先签名再回头看。
- 「还可以发放」是打开页面时读到的。管理员刚注资后，先刷新页面，再看通过按钮是否打开。
- 不要为了让按钮可点而要求编辑人把一批拆得看不清来源。超过 100 个地址本来就要分成多批，每一批都单独审核。
- 不要把完整名单转发到公开群。
- 页面提示合约已暂停、名单与记录不一致、或当前账户不是合约上的审核人时，停止签名，把原文发给管理员。
