# CKEY 空投编辑人操作说明

适用对象：负责整理并发放名单的编辑人。  
操作页面：https://www.freedao.life/admin/airdrop  
登录要求：必须使用管理员发给你的编辑人钱包登录。别的钱包打得开网站，也进不了这个页面。

编辑人只负责上传名单，并把核对过的名单提交上链。上传和提交上链都不会把 CKEY 转到用户钱包。用户要等审核人通过之后，自己登录领取。

## 1. 进入页面

1. 用编辑人钱包登录 https://www.freedao.life 。
2. 打开 https://www.freedao.life/admin/airdrop 。
3. 确认页面标题是「空投发放」，并看得到「选择 CSV」。
4. 看页面上的两行数字：
   - 「还可以发放」是合约里目前还能拿来发放的 CKEY。
   - 「单个地址单次不超过」是当前这一次、每一个地址最多能发多少。默认 500 CKEY，管理员可以改。以页面上显示的数字为准。

浏览器里钱包当前选中的账户，必须就是登录网站的这个地址。选错账户时，签名会失败。每次签名还需要钱包里有少量 BNB 支付手续费。

## 2. CSV 格式

文件保存成 CSV 即可。上传时会自动识别 UTF-8、GBK、GB2312 和 GB18030，Windows 里 Excel 另存的「CSV（逗号分隔）」可以直接用。不要用带千分位的表格，也不要保存成 `.xls` 或 `.xlsx`。

第一行可以写表头，也可以不写。表头必须是：

```csv
address,amount,reason
```

每一行三列，不能多，也不能少。

| 列 | 含义 | 要求 |
| --- | --- | --- |
| address | 收款钱包地址 | 完整的 `0x` 加 40 位十六进制。大小写都可以。不能是全 0 地址，不能是短地址、邮箱或手机号。 |
| amount | 这一次发给该地址的 CKEY 数量 | 按枚填写。`100` 表示 100 CKEY，`100.5` 表示 100.5 CKEY。最多 18 位小数。必须大于 0。 |
| reason | 发放理由 | 1 到 200 个字。不能空着，不能换行。 |

示例：

```csv
address,amount,reason
0x1111111111111111111111111111111111111111,100,社区互动
0x2222222222222222222222222222222222222222,100.5,现场签到
```

理由里如果有逗号，整段理由要用英文双引号包起来：

```csv
address,amount,reason
0x1111111111111111111111111111111111111111,100,"社区,互动"
```

整份文件会被拒绝、而且不会存成草稿的情况：

- 某一行不是三列，或引号没有成对。
- 地址无效、是全 0 地址，或同一份文件里同一个地址出现两次。
- 金额是 0、负数、空白、科学计数法（如 `1e2`）或带千分位（如 `1,000`）。
- 小数超过 18 位。
- 某一个地址的金额超过页面上的单次上限。
- 超过 100 行地址。空行不计数。
- 文件大于 1MB。
- 没有有效数据行。

超过 100 个地址时，拆成多份 CSV，每份单独上传、单独提交、单独审核。不要把同一个地址拆成同一份文件里的两行来绕过上限；同一份文件里的重复地址会被拒绝。同一个地址可以出现在另一份文件里，每一份仍受当时的单次上限约束。

## 2.1 线下社区空投

页面上有一个「线下社区空投」复选框。不勾选时，仍使用上面的三列表。

勾选后，CSV 只有地址和理由，不要自己填金额：

```csv
address,reason
0x1111111111111111111111111111111111111111,现场签到
```

入金只读 IDO 合约上该地址的本人入金。没有入金，或未满 100 USDT，发放 10 CKEY。达到 100 USDT 且未满 1000 USDT，发放 50 CKEY。1000 USDT 及以上，发放 100 CKEY。上传成功后，页面立刻写出每个地址的空投数量，并多一列「链上入金」，数字就是当时从合约读到的整数 USDT。某个地址读不到时，整份文件都不会保存。

审核人和管理员不能上传。他们打开名单时，能看到地址、算出的 CKEY，以及这一列链上入金。

## 3. 上传名单

1. 在表格软件里核对地址、金额和理由，再导出 CSV。
2. 普通名单直接点「选择 CSV」。线下社区空投要先勾选，再选择只有地址和理由的文件。
3. 格式合格时，页面出现一条「草稿，未上链」。这时只保存在网站里，没有上链，也没有转出 CKEY。
4. 格式不合格时，页面直接显示哪一项不对。这份文件不会留下草稿。改好后重新选择文件。

上传后在页面上逐行再看一次。钱包里的提交签名看不到每一个地址，所以提交前的核对要在这个页面完成。

## 4. 草稿传错了

名单仍显示「草稿，未上链」，并且还没有提交上链时：

1. 点「删除草稿」。
2. 在确认框里确认删除。
3. 看到「草稿已删除，可以重新上传」后，再上传改好的 CSV。

删除只去掉这份草稿，不转币，也不影响已经审核过的其他批次。

下面几种情况删不掉：

- 已经点过「提交上链」，状态变成「待审核」。页面会提示名单已经提交上链。这时只能请审核人驳回，再上传一份新的 CSV。
- 刚才提交时钱包已经弹出，但页面还没更新。先点「重新核对链上结果」，确认链上到底有没有这笔提交。没有确认之前，不要删，也不要再传一份同样的名单。
- 暂时读不到链。页面不会删除。稍后再试。

## 5. 提交上链

草稿核对无误后，点「提交上链」。

钱包弹出时，里面是这份名单的哈希、条数和合计，不是逐个地址。页面上的名单必须已经核对过。钱包里的账户如果不是当前登录地址，取消签名。

签名成功并核对通过后，状态变为「待审核」。页面提示「已提交上链，等待审核」。

这一步的后果：

- 仍然没有把 CKEY 转给用户。
- 这份名单不能再修改，也不能删除。
- 审核人之后必须提交完全相同的地址和金额，合约才会接受。
- 发现错了，只能请审核人点「驳回」。驳回不会转币。驳回之后，这份批次保持「已驳回」，你再上传一份新的 CSV。

有地址超过单次上限时，「提交上链」是关着的。删除草稿，把超限的金额改小或拆到管理员允许的范围后重新上传。

「还可以发放」不够这一批时，页面会标红。这时仍可以提交上链，但审核人的通过按钮会保持关闭，直到管理员注资。提交前最好先告诉管理员差额。

合约暂停时，不会打开钱包。停止操作并联系管理员。

## 6. 签名之后页面没有更新

不要立刻再传一份同样的名单，也不要反复点「提交上链」。

点「重新核对链上结果」。这个按钮只向链上查询并补登记，不会再要一次新签名。

- 链上已经成功：页面会变成「待审核」。
- 链上还查不到：等几分钟再核对。
- 交易已回滚：页面会解除等待。看清原因后再决定要不要重新提交这一份草稿。

## 7. 各操作的后果

| 操作 | 是否要钱包签名 | 是否转出 CKEY | 之后还能不能改这份名单 |
| --- | --- | --- | --- |
| 选择 CSV，上传成功 | 否 | 否 | 能。删除草稿后重传。 |
| 上传失败 | 否 | 否 | 没有留下草稿。 |
| 删除草稿 | 否 | 否 | 原草稿消失。可以上传新文件。 |
| 提交上链成功 | 是 | 否 | 不能。错了只能请审核人驳回，再传新文件。 |
| 审核人驳回 | 审核人签名 | 否 | 这份批次结束。编辑人上传新文件。 |
| 审核人通过并发放 | 审核人签名 | 先记入用户可领取额度，用户自己领取时才转到用户钱包 | 不能在这个页面撤回。发错立刻联系管理员。 |

## 8. 注意事项

私钥和助记词只放在你自己的钱包里。网站、客服、管理员都不会向你要私钥或助记词。任何让你导出私钥、朗读助记词、或把助记词输入网页的要求，都不要照做。

如果编辑人钱包的私钥或助记词已经泄露，或者你怀疑已经泄露：

1. 立刻停止用这个钱包签名，也不要再接收别人转来的资产到这个地址。
2. 马上告诉管理员：哪一个地址可能不安全、大约什么时间发生。用你们平时的联系方式说，不要把私钥或助记词发给管理员，也不要发到群里。
3. 等管理员关掉旧地址并启用新钱包。管理员会告诉你新的编辑人地址。旧地址被关掉之前，不要继续上传或提交。
4. 新钱包登录后，再从第 1 节重新开始。旧钱包上还没提交的草稿不会自动转到新钱包。

其他事项：

- 一个地址不能同时当编辑人和审核人。如果页面提示当前钱包不能进入，把完整地址发给管理员核对名单。
- 不要把名单发到公开群。CSV 里有收款地址和金额。
- 提交上链前，再次确认没有把测试地址、交易所充值地址或抄错的地址放进去。提交之后不能自行删除。
- 审核通过后，用户必须用名单上的那个钱包登录个人中心，点「立即领取」。币不是在你点「提交上链」时转出的。
- 页面读不到链、或提示合约已暂停时，不要连续点击签名。记下页面原文，交给管理员。
